# Example Company — engineering onboarding

This is a fictional company document for demonstrating the prototype. It does not
describe the real employer's systems. Ask your onboarding buddy for actual access.

## Development environment setup

1. Open your browser and visit https://github.com/settings/keys. On GitHub's SSH and
   GPG keys page, review your existing SSH keys. If your work machine has no key,
   follow GitHub's linked SSH key setup instructions. Never share a private key.
2. Ask your onboarding buddy to invite your work GitHub account to the engineering
   organization. Accept the invitation in your browser. Do not assume access exists
   until GitHub shows that the invitation is accepted.
3. Open Visual Studio Code. Open the Extensions view from the left sidebar
   (View > Extensions is the menu alternative). Find the Python extension published
   by Microsoft and install it. On Windows/Linux, Ctrl+Shift+X opens Extensions;
   on macOS, use Command+Shift+X.
4. In Visual Studio Code, use File > Open Folder to open the repository folder your
   buddy provided. If you do not yet have a repository, ask your buddy for its URL
   and cloning instructions rather than guessing a company address.
5. Read README.md in the repository. Follow that project's documented install and
   test commands manually. Ask the buddy if any command requests credentials or
   elevated permissions. Never paste secrets into the companion.
6. Confirm with your buddy that the development environment works. Record the result
   in your onboarding checklist. The assistant cannot verify tests from conversation.

## Support and ownership

The engineering onboarding buddy handles repository access and environment setup.
IT handles device enrollment, company VPN, and account recovery. Ask IT for the VPN
setup guide; this example document does not contain VPN configuration instructions.
